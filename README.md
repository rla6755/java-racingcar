# 자동차 경주 게임
## 진행 방법
* 자동차 경주 게임 요구사항을 파악한다.
* 요구사항에 대한 구현을 완료한 후 자신의 github 아이디에 해당하는 브랜치에 Pull Request(이하 PR)를 통해 코드 리뷰 요청을 한다.
* 코드 리뷰 피드백에 대한 개선 작업을 하고 다시 PUSH한다.
* 모든 피드백을 완료하면 다음 단계를 도전하고 앞의 과정을 반복한다.

## 온라인 코드 리뷰 과정
* [텍스트와 이미지로 살펴보는 온라인 코드 리뷰 과정](https://github.com/next-step/nextstep-docs/tree/master/codereview)

## 기능 목록 (Step 3 - 자동차 경주)

- [ ] 사용자로부터 자동차 대수를 입력받는다.
- [ ] 사용자로부터 시도할 회수를 입력받는다.
- [ ] 입력된 횟수만큼 자동차 경주를 반복 실행한다.
- [ ] 자동차는 0~9 사이의 랜덤 값 중 4 이상일 경우 전진한다.
- [ ] 전진 시 자동차의 위치를 1 증가시킨다.
- [ ] 자동차의 이동 상태를 화면에 출력한다. (예: `---`)
- [ ] 경주가 끝난 후, 각 자동차의 최종 위치를 출력한다.
- [ ] 자동차 한 대를 객체로 추상화하고 이름과 위치를 상태로 가진다.
- [ ] 여러 대의 자동차를 관리하는 일급 컬렉션(CarList 등)을 만든다.
- [ ] 자동차 경주 전체 흐름을 제어하는 RacingGame 클래스를 만든다.
- [ ] 사용자 입력을 처리하는 InputView 클래스를 만든다.
- [ ] 경과 출력 및 결과 출력을 담당하는 OutputView 클래스를 만든다.
- [ ] UI 로직을 제외한 모든 핵심 로직에 단위 테스트를 작성한다.

## 커밋 컨벤션 (AngularJS Commit Message Convention)

- `feat`: 새로운 기능 추가
- `fix`: 버그 수정
- `refactor`: 리팩토링 (기능 변화 없음)
- `test`: 테스트 코드 추가/수정
- `docs`: 문서 변경 (README 등)
- `chore`: 빌드, 설정 등 기타 변경사항
